## 🚀 Как начать использовать

### Шаг 1: Пользователь регистрирует ПК

1. Напишите основному боту: `/start`
2. Используйте команду: `/register Мой_ПК`
3. Скопируйте полученный токен

### Шаг 2: Установка клиента на ПК

**Windows:**
```bash
cd C:\Users\krugl\pc_remote_bot
install_client.bat
```

**Linux/Mac:**
```bash
cd /path/to/pc_remote_bot
chmod +x install_client.sh
./install_client.sh
```

### Шаг 3: Управление

1. Проверьте список ПК: `/mypcs`
2. Выберите активный ПК: `/selectpc 1`
3. Используйте любые команды!

## 🌐 Деплой на Render.com

### Готово к деплою:
✅ `render.yaml` - конфигурация для 3 сервисов + БД
✅ `Procfile` - процессы для запуска
✅ `requirements.txt` - все зависимости
✅ `.env` - переменные окружения (не коммитить!)

### Инструкция:

1. **Создайте репозиторий на GitHub**
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin <your-repo-url>
git push -u origin main
```

2. **Зайдите на https://render.com**
3. **New + → Blueprint**
4. **Подключите GitHub репозиторий**
5. **Render создаст:**
   - pc-remote-bot (основной бот)
   - pc-remote-websocket (WebSocket сервер)
   - pc-remote-admin (админ бот)
   - pc-remote-db (PostgreSQL)

6. **После деплоя:**
   - Скопируйте URL WebSocket сервера
   - Обновите `WS_SERVER_URL` в основном боте
   - Формат: `wss://pc-remote-websocket.onrender.com`
