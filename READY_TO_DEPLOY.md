## 🚀 Шаги для деплоя на Render.com

### 1. Подготовка репозитория

```bash
cd C:/Users/krugl/pc_remote_bot

# Инициализация git (если еще не сделано)
git init
git add .
git commit -m "Initial commit - Production ready v1.0.1"

# Создание репозитория на GitHub
# Перейдите на github.com и создайте новый репозиторий

# Подключение к GitHub
git remote add origin https://github.com/ваш-username/pc-remote-bot.git
git branch -M main
git push -u origin main
```

### 2. Деплой на Render.com

1. Зайдите на https://render.com
2. Нажмите **New +** → **Blueprint**
3. Подключите ваш GitHub репозиторий
4. Render автоматически обнаружит `render.yaml`
5. Нажмите **Apply**

Render создаст автоматически:
- ✅ PostgreSQL база данных
- ✅ WebSocket сервер (web service)
- ✅ Основной бот (background worker)
- ✅ Админ бот (background worker)

### 3. Проверка после деплоя

1. Откройте Dashboard на Render.com
2. Проверьте, что все 4 сервиса запущены (зеленый статус)
3. Откройте логи каждого сервиса
4. Убедитесь, что нет ошибок

### 4. Тестирование

1. Найдите основного бота в Telegram: `@ваш_бот`
2. Напишите `/start`
3. Напишите `/register Тестовый_ПК`
4. Получите токен
5. Запустите клиент на ПК с этим токеном
6. Проверьте команды: `/mypcs`, `/info`, `/screen`

## 🆘 Если что-то пошло не так

### Боты не отвечают
- Проверьте логи на Render.com
- Убедитесь, что все сервисы запущены
- Проверьте переменные окружения

### Клиент не подключается
- Проверьте `WS_SERVER_URL` - должен быть `wss://` (не `ws://`)
- Убедитесь, что WebSocket сервис запущен
- Проверьте токен клиента

### База данных не работает
- Убедитесь, что PostgreSQL сервис создан
- Проверьте `DATABASE_URL` в переменных окружения
- Проверьте логи миграций
