## 🚀 СЛЕДУЮЩИЙ ШАГ: Деплой на Render.com

### Шаг 1: Зайдите на Render.com

1. Откройте https://render.com
2. Войдите или зарегистрируйтесь (можно через GitHub)

### Шаг 2: Создайте Blueprint

1. Нажмите **New +** → **Blueprint**
2. Подключите GitHub аккаунт (если еще не подключен)
3. Выберите репозиторий: **wakaexe/pc-remote-control-bot**
4. Render автоматически обнаружит файл `render.yaml`
5. Нажмите **Apply**

### Шаг 3: Настройте переменные окружения

Render создаст 4 сервиса автоматически. Вам нужно добавить только один секретный ключ:

1. Откройте каждый сервис (main bot, admin bot, websocket)
2. Перейдите в **Environment**
3. Добавьте переменную:
   - **Key:** `GROQ_API_KEY`
   - **Value:** `your_groq_api_key_here`

### Шаг 4: Обновите WS_SERVER_URL

После того как WebSocket сервис запустится:

1. Скопируйте URL WebSocket сервиса (например: `https://pc-remote-websocket.onrender.com`)
2. Откройте настройки Main Bot и Admin Bot
3. Обновите переменную `WS_SERVER_URL`:
   - Замените `ws://localhost:8765` на `wss://pc-remote-websocket.onrender.com`
4. Сохраните и перезапустите сервисы

### Шаг 5: Дождитесь запуска

Render автоматически:
- ✅ Создаст PostgreSQL базу данных
- ✅ Установит зависимости
- ✅ Запустит все 4 сервиса
- ✅ Подключит базу данных

Это займет 5-10 минут.

## 📊 Структура сервисов на Render.com

После деплоя у вас будет:

1. **pc-remote-db** (PostgreSQL) - база данных
2. **pc-remote-websocket** (Web Service) - WebSocket сервер
3. **pc-remote-bot** (Background Worker) - основной бот
4. **pc-remote-admin** (Background Worker) - админ бот

## 🔑 Важные переменные окружения

Эти переменные уже настроены в `render.yaml`, но проверьте их:

### Main Bot
- `TELEGRAM_BOT_TOKEN` - токен основного бота
- `ADMIN_ID` - ваш Telegram ID
- `GROQ_API_KEY` - ключ Groq API (добавьте вручную!)
- `DATABASE_URL` - подключается автоматически
- `WS_SERVER_URL` - обновите после запуска WebSocket

### Admin Bot
- `ADMIN_BOT_TOKEN` - токен админ бота
- `ADMIN_ID` - ваш Telegram ID
- `DATABASE_URL` - подключается автоматически

### WebSocket Server
- `WS_SERVER_HOST` - 0.0.0.0
- `WS_SERVER_PORT` - 10000
- `DATABASE_URL` - подключается автоматически

## 🆘 Если что-то не работает

### Сервисы не запускаются
- Проверьте логи на наличие ошибок
- Убедитесь, что все переменные окружения установлены
- Проверьте, что PostgreSQL база создана

### Боты не отвечают
- Проверьте токены ботов
- Убедитесь, что `ADMIN_ID` правильный
- Проверьте подключение к базе данных

### Клиент не подключается
- Убедитесь, что `WS_SERVER_URL` правильный (должен быть `wss://`, не `ws://`)
- Проверьте, что WebSocket сервис запущен
- Проверьте токен клиента
