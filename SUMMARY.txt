🎓 QUICK START
═══════════════════════════════════════════════════════════════════════════════

1. Get credentials:
   - Telegram Bot Token from @BotFather
   - Your Telegram ID from @userinfobot
   - DeepSeek API Key (optional)

2. Install:
   cd ~/pc_remote_bot
   pip install -r requirements.txt
   cp .env.example .env
   nano .env  # Add your credentials

3. Run:
   python main.py

4. Test:
   Send /start to your bot in Telegram
