# 🤖 Бот удалённого управления ПК

Мощный Telegram-бот для удалённого управления компьютером с интеграцией AI-ассистента (DeepSeek). Управляйте своим ПК из любой точки мира через Telegram.

**🇷🇺 Полностью на русском языке!**

## ✨ Возможности

### 🖥️ Управление системой
- Информация о системе (CPU, RAM, диски, аптайм, IP)
- Выполнение команд терминала
- Выключение/перезагрузка/блокировка/сон
- Управление процессами (список, завершение)

### 📁 Управление файлами
- Просмотр директорий с навигацией
- Скачивание файлов (до 50МБ)
- Загрузка файлов на ПК
- Создание/удаление папок
- Древо директорий

### 📸 Управление экраном
- Скриншоты
- Поддержка нескольких мониторов

### ⌨️ Управление вводом
- Печать текста удалённо (поддержка кириллицы)
- Нажатие комбинаций клавиш (Ctrl+C, Win+R и т.д.)
- Управление мышью (клик, перемещение, прокрутка)
- Получение позиции мыши и цвета пикселя

### 📋 Буфер обмена
- Получение содержимого буфера
- Установка содержимого буфера

### 🤖 AI-ассистент (DeepSeek)
- Управление ПК на естественном языке
- Понимание команд на русском
- История диалога
- Автоматическое выполнение действий

### 🔒 Безопасность
- Авторизация по Telegram ID
- Ограничение частоты команд (10/мин)
- Логирование всех действий
- Подтверждение опасных операций
- Санитизация путей файлов

## 📦 Установка

### Требования
- Python 3.10 или выше
- Telegram Bot Token (от @BotFather)
- Ваш Telegram ID (от @userinfobot)
- DeepSeek API Key (опционально, для AI)

### Быстрая установка

```bash
# 1. Клонировать репозиторий
cd ~
git clone <repo-url> pc_remote_bot
cd pc_remote_bot

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Настроить
cp .env.example .env
nano .env  # Добавить ваши данные

# 4. Запустить
python main.py
```

### Настройка .env

```env
# Обязательные параметры
TELEGRAM_BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id

# Опционально (для AI)
DEEPSEEK_API_KEY=ваш_ключ_deepseek

# Режим работы
BOT_MODE=polling  # для локального запуска
```

## 📱 Использование

### Основные команды

```
/start          - Приветствие и главное меню
/help           - Справка по всем командам
/info           - Информация о системе
/screen         - Сделать скриншот
/ps             - Список процессов
```

### Системные команды

```
/shell <команда>  - Выполнить команду в терминале
/shutdown         - Выключить ПК (задержка 60 сек)
/reboot           - Перезагрузить ПК (задержка 60 сек)
/abort            - Отменить выключение/перезагрузку
/lock             - Заблокировать ПК
/sleep            - Перевести в режим сна
/kill <PID>       - Завершить процесс
```

### Управление файлами

```
/ls [путь]           - Список файлов в папке
/download <путь>     - Скачать файл
/upload              - Загрузить файл (ответить на файл)
/mkdir <путь>        - Создать папку
/rm <путь>           - Удалить файл/папку
/tree [путь]         - Показать древо папок
```

### Управление вводом

```
/type <текст>              - Напечатать текст
/press <клавиши>           - Нажать комбинацию (например: Ctrl+C)
/mousepos                  - Позиция мыши
/click <x> <y> [кнопка]    - Кликнуть по координатам
/move <x> <y>              - Переместить мышь
/scroll <количество>       - Прокрутить колёсико
```

### Буфер обмена

```
/clip_get           - Получить содержимое буфера
/clip_set <текст>   - Установить содержимое буфера
```

### AI-ассистент

```
/ai <сообщение>     - Отправить сообщение AI
/exit_ai            - Выйти из режима чата с AI
```

**Примеры для AI:**
- "Сделай скриншот"
- "Покажи информацию о системе"
- "Напечатай Привет мир"
- "Сколько свободной памяти?"

## 🐛 Решение проблем

### Бот не отвечает
1. Проверьте, что бот запущен
2. Проверьте ADMIN_ID в .env
3. Проверьте логи: `cat logs/bot.log`

### "Access denied"
Ваш Telegram ID не совпадает с ADMIN_ID в .env. Получите свой ID от @userinfobot.

### PyAutoGUI не работает
- **Windows**: Убедитесь, что вы залогинены с дисплеем
- **Linux**: Установите Xvfb: `sudo apt install xvfb`
- Запустите: `xvfb-run python main.py`
