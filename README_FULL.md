# 🤖 PC Remote Control Bot - Полная версия

## 🎉 Что это?

**Мультипользовательский Telegram бот** для удалённого управления компьютером с AI-ассистентом, базой данных и админ-панелью.

## ✨ Основные возможности:

### 🖥️ Управление ПК:
- ✅ Информация о системе (CPU, RAM, диски)
- ✅ Выполнение команд терминала
- ✅ Управление процессами
- ✅ Выключение/перезагрузка/блокировка
- ✅ Режим сна

### 📸 Медиа:
- ✅ Скриншоты (один/все мониторы)
- ✅ Фото с веб-камеры
- ✅ Список камер

### ⌨️ Управление вводом:
- ✅ Печать текста (Unicode)
- ✅ Нажатие клавиш
- ✅ Управление мышью (клик, движение, прокрутка)
- ✅ Буфер обмена

### 🔊 Звук:
- ✅ Управление громкостью
- ✅ Выключение/включение звука

### 🌐 Сеть:
- ✅ Информация о сети
- ✅ Ping хостов
- ✅ Список WiFi сетей
- ✅ Активные соединения

### 🤖 AI-ассистент (Groq):
- ✅ **Бесплатный навсегда!**
- ✅ Управление на естественном языке
- ✅ Автоматическое выполнение команд
- ✅ Llama 3.3 70B модель

### 👥 Мультипользовательская система:
- ✅ Каждый пользователь управляет своим ПК
- ✅ Автоматическая регистрация
- ✅ База данных (SQLite/PostgreSQL)
- ✅ История команд

### 🔐 Админ-панель (отдельный бот):
- ✅ Статистика пользователей
- ✅ Блокировка/разблокировка
- ✅ Просмотр истории команд
- ✅ Управление системой

## 🚀 Быстрый старт:

### 1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/pc-remote-bot.git
cd pc-remote-bot
```

### 2. Установите зависимости:
```bash
pip install -r requirements.txt
```

### 3. Настройте .env:
```bash
cp .env.example .env
nano .env
```

Заполните:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id
GROQ_API_KEY=ваш_groq_ключ
```

### 4. Запустите:
```bash
python main.py
```

### 5. Используйте:
Откройте Telegram и отправьте боту `/start`

## 🎯 Команды:

### Система:
```
/info - Информация о системе
/shell <команда> - Выполнить команду
/ps - Список процессов
/kill <PID> - Завершить процесс
/shutdown - Выключить ПК
/reboot - Перезагрузить ПК
/lock - Заблокировать ПК
/sleep - Режим сна
```

### Медиа:
```
/screen - Скриншот
/camera - Фото с камеры
```

### Ввод:
```
/type <текст> - Напечатать текст
/press <клавиши> - Нажать клавиши
/click <x> <y> - Кликнуть мышью
```

### Звук:
```
/volume [0-100] - Громкость
/mute - Выключить звук
/unmute - Включить звук
```

### Сеть:
```
/netinfo - Информация о сети
/ping <хост> - Пинг
/wifi - WiFi сети
```

### AI:
```
/ai <сообщение> - Общение с AI
/exit_ai - Выйти из чата
```
