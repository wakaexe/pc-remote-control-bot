# 🔐 Настройка Админ-панели

## Что это?

Админ-бот - это **отдельный Telegram бот** для управления пользователями основного бота.

## Возможности админ-панели:

✅ **Статистика:**
- Общее количество пользователей
- Активные/заблокированные пользователи
- Онлайн пользователи
- Статистика команд

✅ **Управление пользователями:**
- Просмотр списка всех пользователей
- Блокировка/разблокировка пользователей
- Просмотр информации о пользователе
- История команд пользователя

✅ **Рассылка:**
- Отправка сообщений всем пользователям

## Как настроить:

### 1. Создайте второй бот для админки

1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте `/newbot`
4. Дайте имя: `PC Remote Admin Bot`
5. Дайте username: `your_pc_admin_bot`
6. **Скопируйте токен** (например: `7234567890:AAEeCYk5v_s_PSkE7AXYv-koSEyeG5Uv8JM`)

### 2. Добавьте токен в .env

Откройте `.env` и добавьте:

```env
# Admin Bot Configuration
ADMIN_BOT_TOKEN=7234567890:AAEeCYk5v_s_PSkE7AXYv-koSEyeG5Uv8JM
```

### 3. Запустите админ-бота

```bash
python admin_bot.py
```

### 4. Используйте админ-панель

Откройте Telegram и найдите вашего админ-бота, отправьте `/start`

## Команды админ-панели:

```
/start - Главное меню
/stats - Статистика пользователей
/users - Список всех пользователей
/ban <user_id> - Заблокировать пользователя
/unban <user_id> - Разблокировать пользователя
/user <user_id> - Информация о пользователе
/commands <user_id> - История команд
```

## Примеры использования:

**Заблокировать пользователя:**
```
/ban 123456789
```

**Разблокировать пользователя:**
```
/unban 123456789
```

**Посмотреть информацию:**
```
/user 123456789
```

## Безопасность:

- ⚠️ Только ваш ADMIN_ID может использовать админ-бота
- ⚠️ Храните ADMIN_BOT_TOKEN в секрете
- ⚠️ Не давайте доступ к админ-боту другим людям

## Запуск обоих ботов одновременно:

**Windows:**
```bash
# Терминал 1 - Основной бот
python main.py

# Терминал 2 - Админ-бот
python admin_bot.py
```

**Linux (с screen):**
```bash
# Основной бот
screen -S main_bot
python main.py
# Ctrl+A, D для выхода

# Админ-бот
screen -S admin_bot
python admin_bot.py
# Ctrl+A, D для выхода
```
