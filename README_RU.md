# PC Remote Control Bot 🤖

Мощный Telegram-бот для удалённого управления компьютером с интеграцией AI-ассистента (DeepSeek). Управляйте своим ПК из любой точки мира через Telegram.

## ✨ Возможности

### 🖥️ Управление системой
- Информация о системе (CPU, RAM, диски, аптайм, IP)
- Выполнение команд терминала
- Выключение/перезагрузка/блокировка/сон
- Управление процессами

### 📁 Управление файлами
- Просмотр директорий
- Скачивание файлов (до 50МБ)
- Загрузка файлов на ПК
- Создание/удаление папок

### 📸 Управление экраном
- Скриншоты
- Поддержка нескольких мониторов

### ⌨️ Управление вводом
- Печать текста удалённо
- Нажатие комбинаций клавиш
- Управление мышью

### 🤖 AI-ассистент
- Управление ПК на естественном языке
- Интеграция с DeepSeek

## 📦 Установка

### Требования
- Python 3.10+
- Telegram Bot Token (от @BotFather)
- Ваш Telegram ID (от @userinfobot)

### Быстрая установка

```bash
# 1. Клонировать репозиторий
git clone <repo-url> pc_remote_bot
cd pc_remote_bot

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Настроить
cp .env.example .env
nano .env  # Добавить ваши данные

# 4. Запустить
python main.py
```

## 📱 Использование

### Основные команды

```
/start - Приветствие и меню
/help - Справка по командам
/info - Информация о системе
/screen - Скриншот
/ps - Список процессов
/shell <команда> - Выполнить команду
/ai <сообщение> - AI-ассистент
```

### Управление системой

```
/shutdown - Выключить ПК
/reboot - Перезагрузить ПК
/lock - Заблокировать ПК
/sleep - Режим сна
```

### Управление файлами

```
/ls [путь] - Список файлов
/download <путь> - Скачать файл
/upload - Загрузить файл
/mkdir <путь> - Создать папку
/rm <путь> - Удалить файл
```

### Управление вводом

```
/type <текст> - Напечатать текст
/press <клавиши> - Нажать комбинацию
/click <x> <y> - Кликнуть мышью
/mousepos - Позиция мыши
```
