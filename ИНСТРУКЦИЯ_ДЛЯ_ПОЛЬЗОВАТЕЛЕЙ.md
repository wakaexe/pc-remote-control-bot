# 📱 Как подключить свой ПК к боту - ПРОСТАЯ ИНСТРУКЦИЯ

## Для пользователя (3 простых шага)

### Шаг 1: Получите токен от бота

1. Найдите бота в Telegram (токен: `8668239227:AAEeCYk5v_s_PSkE7AXYv-koSEyeG5Uv8JM`)
2. Напишите боту: `/start`
3. Напишите боту: `/register Мой_Компьютер`
4. Бот пришлёт вам **ТОКЕН** - скопируйте его!

**Пример токена:**
```
xK9mP2vL4nQ8rT6wY3zA1bC5dE7fG0hJ9iK2lM4nO6pQ8rS1tU3vW5xY7zA9bC
```

---

### Шаг 2: Скачайте программу на ПК

**Вариант А: Простой (для Windows)**

1. Скачайте файлы с GitHub
2. Найдите файл `install_client.bat`
3. **Запустите его двойным кликом**
4. Программа спросит токен - **вставьте токен из Шага 1**
5. Программа спросит URL сервера - **нажмите Enter** (оставьте по умолчанию)
6. Готово! Программа установится и запустится

**Вариант Б: Ручная установка**

1. Установите Python 3.11+ с https://www.python.org/downloads/
2. Скачайте файлы проекта
3. Откройте командную строку в папке проекта
4. Выполните:
```bash
pip install -r requirements.txt
```
5. Создайте файл `.env` с содержимым:
```
WS_SERVER_URL=ws://localhost:8765
PC_CLIENT_TOKEN=ваш_токен_из_шага_1
```
6. Запустите:
```bash
python pc_client.py
```

---

### Шаг 3: Проверьте подключение

1. Вернитесь в Telegram к боту
2. Напишите: `/mypcs`
3. Вы увидите свой ПК в списке!
4. Напишите: `/selectpc 1` (выберите ваш ПК)
5. Теперь можете управлять! Попробуйте: `/info`

## ❓ Частые вопросы

### Программа не подключается к боту

**Проблема:** Клиент не может подключиться к серверу

**Решение:**
1. Проверьте, что основной бот запущен
2. Проверьте, что WebSocket сервер запущен
3. Проверьте токен - он должен быть правильным
4. Проверьте firewall - разрешите Python

### Бот не отвечает на команды

**Проблема:** Бот получает команды, но ничего не происходит

**Решение:**
1. Проверьте, что выбран активный ПК: `/mypcs`
2. Если ПК оффлайн (🔴) - запустите клиент на ПК
3. Выберите ПК: `/selectpc 1`
4. Попробуйте снова

### Хочу подключить несколько ПК

**Решение:**
1. На каждом ПК повторите Шаг 1 (получите новый токен)
2. Используйте разные имена: `/register Домашний_ПК`, `/register Рабочий_ПК`
3. Установите клиент на каждый ПК со своим токеном
4. Переключайтесь между ПК: `/selectpc 1`, `/selectpc 2`

### Хочу автозапуск при старте Windows

**Решение:**
1. При установке через `install_client.bat` программа спросит про автозапуск
2. Ответьте `y` (yes)
3. Программа автоматически добавится в автозагрузку

**Или вручную:**
1. Нажмите Win+R
2. Введите: `shell:startup`
3. Создайте файл `start_pc_client.bat` с содержимым:
```batch
@echo off
cd C:\путь\к\pc_remote_bot
python pc_client.py
```
4. Скопируйте файл в открывшуюся папку

## 🔒 Безопасность

- **Токен** - это ваш ключ доступа к ПК. Не давайте его никому!
- Каждый пользователь видит только свои ПК
- Администратор может видеть всех пользователей, но не может управлять их ПК
- Все команды логируются

## 💡 Полезные команды

### Управление ПК
```
/register Имя_ПК          - Зарегистрировать новый ПК
/mypcs                    - Список ваших ПК
/selectpc 1               - Выбрать активный ПК
/renamepc 1 Новое_Имя     - Переименовать ПК
/deletepc 1               - Удалить ПК
```

### Системные команды
```
/info                     - Информация о системе
/screen                   - Скриншот
/shell команда            - Выполнить команду
/ps                       - Список процессов
/shutdown                 - Выключить ПК
```

### AI-ассистент
```
/ai открой браузер        - AI выполнит команду
/ai скачай Chrome         - AI откроет страницу загрузки
/ai найди кошек           - AI откроет поиск
```
